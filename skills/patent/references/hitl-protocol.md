# 人机协作协议（HITL Protocol）

> 专利产出的**人工审批行为规范**。Mady 通过 ApprovalGate（`/approve` `/reject`）实现
> 暂停机制，本协议规定**何时必须暂停、暂停后提供什么材料**。
> （移植自 Sati patent-agent references/hitl-protocol.md，与 Mady ApprovalGate 语义对齐）

## 一、五个通用确认点（任一项触发即暂停等待确认）

1. **事实认定** — 认定关键事实（申请日、公开日、证据来源）前。
2. **法律依据** — 首次适用某法条/审查指南条款得出结论前。
3. **策略选择** — 在"完全反驳 / 部分反驳+修改 / 接受+修改"等策略间取舍前。
4. **修改验证** — 对权利要求/说明书做出实质性修改（如 A33 超范围判断）前。
5. **最终交付** — 任何以"定稿/最终结论"形式输出的内容前。

## 二、OA 答复强制确认点（答复流程必经）

| # | 确认点 | 暂停前必须完成 |
|---|--------|---------------|
| 1 | 审查意见事实认定 | 逐条列出审查员引用的权利要求特征与事实 |
| 2 | 答复法律依据 | 每个论点对应法条/审查指南条款 |
| 3 | 答复策略 | 明示三选一策略及理由 |
| 4 | 修改超范围验证 | 依据专利法第33条核对修改后的文字是否超出原申请记载范围 |
| 5 | 最终答复文本 | 通过 patent_eval(mode="comprehensive") 与 quality-checklist 自查 |

## 三、八类中断指令（用户发出即暂停当前流程）

`停` / `暂停` / `等一下` / `先别改` / `不要定稿` / `复核` / `改为…`（改写指令）/ `放弃当前答复`（重来指令）

收到上述指令后：立即停止当前生成/修改，整理已完成的中间结果，等待用户指示，不得继续推进流程。

## 四、审批记录要求

- 每次人工审批（采纳/修改/拒绝）均写入审批记录（ApprovalStore），包括：触发关键词、AI 原文摘录、人工决策与时间。
- 人改输出后若复现为回归用例，纳入 Golden Benchmark（domains/approval/regression.go）。
