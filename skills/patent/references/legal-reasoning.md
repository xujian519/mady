# 法律推理五步法（Legal Reasoning）

> 面向专利/法律分析类产出的**推理链规范**。配合五步工作法的"检查"环节使用，
> 核心约束：**任何结论必须由"大前提（法条/规则）+ 小前提（案件事实）"推出，
> 缺一不可，禁止跳跃**。
> （移植自 Sati patent-agent references/legal-reasoning.md）

## 推理链条

```
① 明确问题 → 把咨询/分析请求转化为可判定的法律问题（含适用场景）
② 定位大前提 → 检索并确认适用的法条/实施细则/审查指南条款（原文）
③ 梳理小前提 → 从证据/权利要求/对比文件中提取与问题相关的事实
④ 推导结论 → 大前提 + 小前提 → 结论（三段论式，逐步推导）
⑤ 验证 → 结论能否被反驳？前提是否完备？引用是否可溯源？
```

## 硬性约束

- **禁止跳步**：不得从"感觉"直接给结论；必须显式列出大前提与小前提。
- **结论可溯源**：结论句中必须能指出所依据的法条与事实（对应 quality-checklist 通用自查第 1 条）。
- **前提要核实**：大前提（法条）须经 `rule_check`/知识库核验原文，小前提（事实）须来自证据或输入，禁止编造。
- **多依据并列**：多个法条支撑同一结论时全部列出，按"上位法 > 下位法"排序引用。
- **冲突处理**：审查指南与专利法冲突时以专利法为准（Tier A P-A08）。

## 示例对照

- 错误："该技术方案不具备创造性。"（无前提）
- 正确："根据专利法第22条第3款（大前提），区别特征在对比文件D1中已给出技术启示（小前提），因此该技术方案不具备创造性（结论）。"

## 应用场景

- 新颖性/创造性/充分公开判断
- 侵权（全面覆盖/等同原则）与抗辩分析
- OA 答复中的法律论证
- 无效宣告/驳回复审理由论证
