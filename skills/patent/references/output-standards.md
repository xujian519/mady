# 专利输出标准（Output Standards）

> 面向专利检索报告、分析报告、撰写文书、OA 答复等全部产出的**统一输出规范**。
> 每份产出交付前对照本清单自检；引用与格式不符合本标准的产出不得定稿。
> （移植自 Sati patent-agent references/output-standards.md，按 Mady 现状裁剪）

## 1. 法条引用格式

- **精确到条/款/项**：引用法条必须写明"专利法第X条第X款"或"实施细则第X条"，禁止只写"根据相关法律规定"。
- **注明版本**：法条适用现行有效版本（专利法 2020 修正、实施细则 2023 修订）；版本漂移敏感条款以"现行《专利法》"为准，不臆测历史版本内容。
- **可核验**：关键结论的法条依据必须可经 `rule_check` / 知识库核验，禁止编造条文号或条款内容。
- **审查指南引用**：写明章节号（如"审查指南第二部分第二章§2.2.6"），与法条互为佐证时先法条后指南。

## 2. 编号层级

专业文书统一编号层级，禁止混用：

```
一、 …（第一级，中文数字）
（一）…（第二级，中文数字加括号）
1. …（第三级，阿拉伯数字加句点）
（1）…（第四级，阿拉伯数字加括号）
```

## 3. 对比文件引用（D 编号规则）

- 对比文件首次出现时用**全称 + "下称D1"**：如"对比文件1（CN112345678A，下称D1）"。
- 后续一律用 D1/D2 简称，禁止中途改称。
- 新颖性/创造性分析中引用 D 编号必须与检索报告中的对比文件一一对应，禁止 D 编号错位。

## 4. 术语一致性

- 全文术语保持统一：同一技术特征在同一案件中禁止"限位部/限位件/限位凸台"混用。
- 首次出现可加括号注英文或别称，后续一律用主术语。
- 与权利要求书用语保持一致（权利要求怎么写，说明书/答复就怎么引用）。

## 5. 引用标注来源

- 报告中引用的事实（数据、文献、判例、专利）必须标注来源与出处。
- 检索类产出必须明确**检索范围、检索式、数据来源、检索日期**，并标注未检索的数据库。

## 6. 交付结构

分析类产出建议按以下骨架组织，确保持续可追溯：

```
一、结论摘要（含风险定级）
二、依据与推理（法条 + 事实 + 推理链）
三、对比/证据明细（表格化）
四、风险提示与免责声明
```
