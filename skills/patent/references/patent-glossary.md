# 专利术语表（Patent Glossary）

> 专利分析中的**关键术语统一口径**。产出中凡出现下表术语，必须按下述含义使用，
> 避免与日常语义混淆。用于保证跨产出的术语一致性（配合 output-standards.md 第 4 条）。
> （移植自 Sati patent-agent references/patent-glossary.md，按 Mady 实务裁剪）

| 术语 | 标准含义 | 易混淆点 |
|------|---------|---------|
| 现有技术 | 申请日（含优先权日）以前在国内外为公众所知的技术（专利法22条5款） | ≠ 检索到的全部文献；须先判断公开日 |
| 对比文件 | 用于比对的现有技术文献，报告内统一 D1/D2 简称 | 勿与"引证文件"混淆 |
| 区别特征 | 权利要求技术特征与最接近现有技术（D1）不同的部分 | 在创造性三步法第 2 步确定 |
| 特定技术特征 | 单一性判断中体现发明对现有技术贡献的技术特征（实施细则43条） | ≠ 一般技术特征 |
| 惯用手段直接置换 | 所属领域惯常手段的直接替换，无预料不到的技术效果（审查指南3.2.1.1） | 新颖性判断中的置换 ≠ 创造性中的公知常识结合 |
| 公知常识 | 本领域技术人员普遍知晓的技术手段/知识（如教科书、工具书内容） | 需举证来源，不凭经验断言 |
| 预料不到的技术效果 | 从现有技术不能直接、毫无疑义地推出的效果（审查指南3.2.3） | 须有数据/对比支撑 |
| 技术启示 | 现有技术给出将区别特征应用到最接近现有技术以解决技术问题的教导 | 三步法第 3 步核心判断对象 |
| 单独对比原则 | 新颖性判断中：一项权利要求只与一篇对比文件单独对比，禁止组合 | 创造性允许组合，新颖性禁止 |
| 全面覆盖原则 | 侵权判定：被诉方案包含权利要求全部技术特征即落入保护范围 | 配合等同原则适用 |
| 等同特征 | 以基本相同手段、实现基本相同功能、达到基本相同效果的技术特征 | 三基本相同 + 无需创造性联想 |
