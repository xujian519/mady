# 交付前质量自查清单（Quality Checklist）

> 通用质量自查：每份专利产出在 **patent_eval 预检之后、人工复核之前** 执行。
> 按产出类型选择对应专项清单（claim/spec/oa），本文为**跨类型通用门禁**。
> （移植自 Sati patent-agent references/quality-checklist.md）

## 一、通用自查五问（逐条回答"是"才可交付）

1. **结论可溯源** — 每个结论能否追溯到具体法条 + 具体事实（证据/权利要求/对比文件页码）？
2. **引用已核实** — 引用的法条、判例、专利号、文献是否经检索/知识库核验，而非凭记忆？
3. **检索充分** — 结论依赖的现有技术检索是否覆盖关键分类号与关键词变体？是否标注了未检索范围？
4. **无遗漏** — 权利要求逐项比对是否无遗漏特征？答复是否覆盖全部驳回理由？
5. **无绝对化表述** — 是否已排除"绝对/一定/百分百/毫无疑问/必然"等绝对化措辞（Tier A P-A07）？

## 二、场景化门控阈值

### OA 答复（强制，任一不过不得定稿）

| 维度 | 门槛 | 说明 |
|------|------|------|
| 事实认定 | 须逐条核对审查意见引用的权利要求特征与事实 | 事实认定错误 = 全盘失守 |
| 法律依据 | 每个答复论点必须有对应法条/审查指南依据 | 无依据论点必须删除 |
| 答复策略 | 明确选择"完全反驳/部分反驳+修改/接受+修改"三选一 | 禁止策略含糊 |
| 成文质量 | 结构完整、无套话（见 stop-slop.md）、引用格式规范（见 output-standards.md） | 满足评分标准 |

### 分析报告（强制）

- 综合分（comprehensive）≥ 0.7 方可交付；低于 0.7 必须修订后重新评估。
- 风险类结论（侵权/无效/新颖性/创造性）必须有人工复核留痕（hitl-protocol.md）。

## 三、门控动作

- 任一必查项不通过 → **不得交付**，回到对应环节修订并重新评估。
- 自查结果随产出一同提交人工复核（ApprovalGate），作为审批上下文。
