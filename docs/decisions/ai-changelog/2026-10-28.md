# 2026-10-28

## fix(browser): 迁移至 chromedp 0.21 泛型 Action API

**背景**：dependabot 将 chromedp 0.16.0 升至 0.21.0，上游改为泛型 `Action[T]` API，移除 `ActionFunc`、`ByQuery`、`NewRemoteAllocator`、`ListenTarget` 及命令式 `.Do(ctx)`，导致 lint/test/desktop/example/integration 全部构建失败。

**改动清单**：
- allocator：`NewRemoteAllocator` → `remote.NewAllocator`
- 动作：多参 `Run` → `Do`；`ActionFunc` → `Func`；`ByQuery`/`BySearch` → `CSS`/`Search`
- 取值动作：`Title`/`Location`/`CaptureScreenshot`/`Evaluate` 改为泛型返回值 + 单动作 `Run`
- 事件：`ListenTarget` → `cdp.Events` 迭代器
- 直接协议命令：`page.X().Do(ctx)` → `chromedp.Call` / `cdp.Call`

**验证**：`go build ./...`、`go vet ./...`、`golangci-lint run ./...`（0 issue）、`go test ./tools/... ./domains/doctmpl/...` 全部通过。

**影响**：对外行为保持一致；录制器改用 cdproto 已解码的帧字节；停止录屏使用 `context.WithoutCancel` 保证清理命令可达。

## feat(pkg): 新增 pkg/indexasset 领域索引资产格式与 fail-closed 约定

**背景**：三域引入的 W0 基座要求法条、费用、日历等手工转录资产共用一套字段规则。若各模块自行解析，「有条文、无来源仍被判为已核验」这类 fail-open 状态在加载期无法拦截，法律结论会建立在无出处的文本上。

**改动清单**：
- 新增 `pkg/indexasset`：YAML 根映射解析、严格字段读取器（字符串/日期/计数/布尔/枚举/主题词/条目录）、`RequireKnownFields` 未知字段拒绝、来源记录 `sourceDoc`+`verifiedOn` 的全有或全无校验、`ReadArticleEntries` 重复条号拒绝。
- 兼容 yaml.v3 差异：未加引号的 `2026-09-26` 会被解析为 `time.Time`，读取器同时接受字符串与时间戳并统一为 `YYYY-MM-DD`。
- 新增 `docs/design/index-asset-format.md`：随包资产（模块内 embed）与外置资产（$MADY_HOME/根 data）的分发判据、目录布局、字段规则、来源三态语义。
- 新增 `docs/design/fail-closed-matrix.md`：11 条拒绝语义（法条未转录/无索引/越界、费用未转录、日历缺年份、出件断言、交付件不一致等）与允许降级清单。
- 新增 `scripts/asset-fingerprint` 与 `data/ASSETS.sha256`：转录类事实索引的 SHA-256 漂移校验，白名单只含 `data/law`、`pkg/lawcite/data`、`domains/fees/data`、`domains/deadline/data`。
- 资产格式移植自 deepseek-harness `packages/patent/patent-index-asset`，按 Go 习惯改为错误工厂 + `*indexasset.Error`。

**验证**：`go test -race ./pkg/indexasset/...` 通过（语句覆盖率 95.5%）、`go vet` 与 `go build ./pkg/... ./domains/...` 通过、指纹脚本生成/校验/篡改检测/幂等 4 项自测通过、`scripts/check-doc-consistency.py` 通过。

**影响**：新增纯库，无既有调用方。`data/ASSETS.sha256` 当前为空清单，W1 落位法条资产后自动填充；指纹脚本白名单不含规则包与模板，避免手写资产变更制造无效告警。
