## fix(disclosure): 整体置信度按最低等级聚合

**背景**：aggregateNoveltyResult 的聚合 switch 会把所有非 low/medium 的置信度（含空串/未知值）当作 high，且 all-high 时整体值会被错误降为 medium。探针：两条 high → 整体 medium。

**改动清单**：
- 显式区分 high/medium/其他分支，未知或缺失按 low 处理。
- 新增表驱动测试覆盖 all-high / high+medium / high+low / 未知值 4 种组合。

**验证**：go test ./disclosure -run TestAggregateNoveltyResult 全绿。

**影响**：仅影响报告中的整体置信度标注，不改变逐特征结论。

## fix(disclosure): batch 模式新颖性评估校验引用证据 ID

**背景**：逐特征路径用 validateCitedEvidenceIDs 剔除编造 doc_id，batch 路径（默认 provider / 无 JSON Schema）未校验，模型虚构证据会进入报告。

**改动清单**：
- parseNoveltyOutput 反序列化后对每条 FeatureAssessment 复用 validateCitedEvidenceIDs，剔除无效 ID、追加说明、high 降 medium。
- 新增 TestParseNoveltyOutput_ValidatesCitedEvidenceIDs 回归测试。

**验证**：go test ./disclosure -run 'TestParseNoveltyOutput|TestAggregateNoveltyResult' 全绿。

**影响**：仅收敛 batch 模式的引用字段与置信度，无 API/协议面变更。

## fix(disclosure): 逐特征评估强制回填请求特征 ID

**背景**：parsePerFeatureOutput 只在模型未返回 feature_id 时回填请求值，模型返回错位 ID 会把结论挂到不存在或错误的特征上。

**改动清单**：
- 无条件以请求 featureID 覆盖模型回填值。
- 新增 TestParsePerFeatureOutput_OverridesMismatchedFeatureID 回归测试。

**验证**：go test ./disclosure -run TestParsePerFeatureOutput 全绿。

**影响**：仅收敛逐特征结果归属字段，无 API/协议面变更。
