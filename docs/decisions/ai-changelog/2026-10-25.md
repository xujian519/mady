## test(tui): 恢复 TUI 测试基线：ANSI 断言、golden 与离线 Agent 测试

**背景**：TUI 测试在 main 上存在 11 项失败，门禁失去信号价值。失败分两类：断言未剥离 ANSI 样式（配色系统上线后成批误报）、Agent 集成测试依赖真实 API Key（环境中存在失效 key 时稳定 401）。

**改动清单**：
- DebugOverlay / Markdown equivalence / inline-math / collapsed assistant 断言改为对 StripAnsi 后的可见文本或 VisibleWidth 校验
- 按当前色彩系统重生成 4 组卡片 golden（人工确认可见文本零变化）
- TestAgentRunInTUISession 改用内存 fakeStreamProvider，移除 BuildProvider 网络依赖

**验证**：cd tui && go test -count=1 ./...、go test -race -count=1 ./...、golangci-lint run ./... 全部通过。

**影响**：无产品行为变化；测试不再依赖终端配色与网络环境。

## fix(tui): 会话选择器脚注按面板宽度收敛

**背景**：SessionSelector 的帮助脚注固定 122 列，在 120 列终端下溢出面板；作为 40% 宽 overlay 挂载时实际宽度只有 40~60 列，提示被整体裁掉。

**改动清单**：
- 脚注按宽度断点降级（full/medium/small），最终行宽恒等于 Render 传入的 width
- 新增 32/40/48/60/80/120 宽度矩阵测试
- 移除原测试中因行首 ANSI 而失效的跳过条件

**验证**：go test -count=1 ./component/ -run TestSessionSelector；go test -race -count=1 ./... 通过。

**影响**：窄面板下仍保留搜索/导航/关闭提示；任何宽度不再溢出。

**验证**：cd tui && go test -count=1 ./...、go test -race -count=1 ./...、golangci-lint run ./... 通过。

**影响**：补齐 TUI↔agent 接线的端到端覆盖；无产品行为变化。
