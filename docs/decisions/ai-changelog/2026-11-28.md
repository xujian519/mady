## fix(agentcore/plantask): M42 plantask 错误映射 fix：ErrSessionNotFound 区分未找到与读取失败

**背景**：终审报告 §五 P2-6 遗留项。`agentcore/plantask/extension.go` 的 `loadSession` 把 `Store.Load` 的所有错误统一映射为 `ErrNoActiveSession`，使 IO、权限、JSON 解析等真实失败被伪装成「无活动会话」，调用方与用户无法察觉底层故障。

**改动清单**：
- `agentcore/plantask/session.go`：新增哨兵错误 `ErrSessionNotFound`，注释说明其与读取失败的区分语义
- `agentcore/plantask/store.go`：`MemoryStore.Load` 未命中时以 `%w` 包装 `ErrSessionNotFound`
- `agentcore/plantask/filestore.go`：`FileStore.Load` 的 `os.IsNotExist` 分支包装 `ErrSessionNotFound`，其余 IO 错误仍带原因上抛
- `agentcore/plantask/extension.go`：`loadSession` 仅将 `id == ""` 与 `errors.Is(err, ErrSessionNotFound)` 映射为 `ErrNoActiveSession`，其余错误原样返回
- `agentcore/plantask/extension_test.go`：新增 `TestLoadSession_IOErrorPropagates`，通过注入 IO 错误的 Store 断言错误原样上抛且非 `ErrNoActiveSession`
