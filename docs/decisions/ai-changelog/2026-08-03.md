## fix(tui): TUI Markdown 列表渲染修复：中文序号规范化与列表对齐

修复 TUI Markdown 渲染器中中文序号列表（一、二、...）会原样泄漏 `、` 标点的问题，并将列表首行与续行缩进从字节长度改为可见列宽计算，解决 CJK 终端下宽字符（•、中文序号等）导致的列表错位。

改动清单：
- `tui/component/markdown_render.go`：中文序号列表渲染为 `一. ` 形式，与其他有序列表风格统一；bullet/ordered/中文 ordered 三类列表均使用 `core.VisibleWidth` 计算前缀宽度，续行按可见列宽对齐；续行渲染前剥离源码缩进，避免缩进被重复叠加导致列表错位。
- `tui/go.mod` / `tui/go.sum`：`go mod tidy` 补全 `golang.org/x/text` 依赖（`tui/core/width.go` 已引入使用）。
